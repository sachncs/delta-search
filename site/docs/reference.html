Docs / API reference

Names you can build on.

This is a practical map of the public surface. For exact signatures and edge cases, jump from a symbol to its module in the repository.

Graph data structures

SymbolUse it forNotes
Graph[NodeT]Undirected graph storage.Adjacency and edge lookups are constant time. Nodes must be hashable and orderable for stable sorting.
ThreadSafeGraph[NodeT]Shared graph access.Uses an RLock. Live views are not compound snapshots.
Graph.from_edgesBuild a graph from edge pairs.Implicitly creates endpoint nodes.
subgraph / edge_subgraphCreate derived graph values.Returns a new graph; verify ownership when attaching attributes.

Domain model

SymbolRoleTypical use
ActionOne candidate mutation.ActionType.ADD_EDGE, remove node, or a domain-specific action.
DeltaResultIncremental score result.Set reward change, penalty change, and feasibility.
DefaultStateSmall state implementation.Use it when your problem needs no extra fields.
UndoEntryRollback record.Usually managed by the problem implementation.
SubgraphExtractionProblemPolymorphic domain boundary.Subclass it for custom reward, penalty, actions, and constraints.

Built-in problems

MaximumPlanarSubgraphProblem

Maximize retained edges with an Euler-bound feasibility heuristic. Validate planarity externally when you need a complete guarantee.

MinimumConnectedDominatingSetProblem

Find a small connected set that dominates every vertex.

MaximumWeightedIndependentSetProblem

Choose a high-weight set of mutually non-adjacent vertices.

PrizeCollectingVertexCoverProblem

Trade vertex costs against uncovered-edge penalties.

UncapacitatedFacilityLocationProblem

Choose facilities and assignments at low total cost.

MinimumWeightedSteinerTreeProblem

Connect terminals through optional nodes and edges.

Budgets and observability

EarlyTerminationCondition accepts max_iterations, max_evaluations, max_time_ms, objective_target, and stall_iterations. Give at least one positive limit when constructing it.

stop = EarlyTerminationCondition(
    max_iterations=500,
    max_time_ms=5_000,
    stall_iterations=40,
)
result = GreedySolver(problem, early_stop=stop).solve(
    observer=MetricsObserver(),
)

Optional integrations

NetworkX conversion lives in delta_search.interop. Visualization helpers require matplotlib. Learned guidance requires scikit-learn. Install these only when you need them with pip install -e ".[all]"; core imports should remain usable without them.
